# FitLog

A modern, responsive workout management web application built for people who want a simple and focused way to discover, plan, save, and track their workouts.

## About the Project

**FitLog** is a dark-themed workout companion where users can browse a workout library, add exercises to their daily plan, save workouts for later, and mark completed workouts as logged.

The project focuses on a clean user experience, responsive design, and practical frontend development using modern React and Next.js features.

## Technologies Used

* **Next.js** — React framework with App Router
* **React** — Component-based UI development
* **Tailwind CSS** — Responsive styling and UI design
* **React Toastify** — Toast notifications for user actions
* **React Icons / Remix Icon** — Interface icons
* **JavaScript (ES6+)** — Application logic and state management
* **Local Storage** — Persisting workout plans and saved workouts

## Key Features

### 1. Workout Library

Browse a collection of exercises with useful information such as:

* Exercise name
* Equipment
* Difficulty
* Sets and reps
* Duration
* Calories burned
* Rating
* Instructions

### 2. Daily Workout Plan

Users can add exercises to **Today's Plan** and manage their daily workout list.

* Add workouts to the plan
* View planned exercises
* Remove workouts
* Track total exercises
* Calculate total workout duration
* Calculate total estimated calories

### 3. Save Workouts for Later

Users can bookmark exercises they want to revisit later.

* Save workouts
* View saved workouts
* Remove saved workouts
* Persistent data using local storage

### 4. Workout Tracking

Users can mark an exercise as completed when they finish it.

* Log completed workouts
* Remove completed workouts from the active plan
* Receive confirmation through toast notifications

### 5. Responsive Dark UI

FitLog is designed to work across different screen sizes with a focused dark fitness interface.

* Mobile responsive
* Tablet responsive
* Desktop responsive
* Responsive workout cards
* Responsive navigation and layouts
* Modern dark theme with lime accent colors
